# Security policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's **Report a vulnerability** button
(Security tab, private vulnerability reporting) to send details privately. Include the
version, configuration and steps to reproduce. You will get an acknowledgement within
7 days.

## Scope notes

netrescale is a self-hosted monitor. Never include real appliance addresses, credentials,
vault or escrow files, `web-users.json`, configuration snapshots or raw syslog in a report
or pull request; sanitize them first.
